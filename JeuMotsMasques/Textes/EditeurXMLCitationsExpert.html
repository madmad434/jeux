📖 Gestionnaire Texte

Gérez vos citations au format XML (structure <citations> / <citation>).

1

📂 Charger un fichier existant

Cliquez sur 📂 Ouvrir XML pour charger un fichier Texte.xml. Les citations s'affichent dans la liste à gauche.

2

✏️ Consulter et modifier

Cliquez sur une citation dans la liste. Passez sur l'onglet ✏️ Édition, modifiez, puis 💾 Sauvegarder.

3

➕ Ajouter une citation

Cliquez sur ➕ Nouvelle Citation. Renseignez l'auteur, le livre et le texte. L'index est attribué automatiquement.

4

💾 Enregistrer sur le disque

Cliquez sur 💾 Enregistrer pour sauvegarder dans Texte_modifie.xml.

❌ Effet du bouton Annuler

En mode Édition (modification d'une citation existante) : les champs reviennent aux valeurs d'origine, aucune modification n'est appliquée.
En mode Nouvelle Citation : la création est abandonnée et la nouvelle entrée (vide) est supprimée. La sélection précédente est restaurée.

⚠️ Important : Sauvegarder enregistre en mémoire uniquement. Utilisez Enregistrer pour écrire définitivement sur le disque.

🆕 Créer un nouveau fichier de zéro

Pas de fichier XML ? Cliquez directement sur ➕ Nouvelle Citation sans rien charger, ajoutez vos citations, puis 💾 Enregistrer pour créer Texte_modifie.xml.
