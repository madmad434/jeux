🎯 Objectif

Retrouvez les mots cachés dans un texte ou un proverbe. Choisissez combien de mots masquer (1 à 5) et le mode qui vous convient le mieux.

🖱️ Mode Glisser / Cliquer

Glissez un mot doré et déposez-le dans une case vide.
Ou cliquez sur un mot doré pour le sélectionner, puis cliquez sur la case vide.
Cliquer sur une case déjà remplie rend le mot à la liste. La vérification est automatique quand toutes les cases sont remplies.

⌨️ Mode Double-clic / Taper

Les mots à retrouver sont affichés à gauche en orange.
Double-cliquez sur un mot orange → il s'insère automatiquement dans la première case vide.
Ou cliquez sur un mot orange pour le sélectionner (il se surligne), puis double-cliquez sur la case où vous voulez le placer.
Vous pouvez aussi taper directement dans les cases.
Appuyez sur Entrée pour passer à la case suivante, La vérification est automatique dès que toutes les cases sont remplies.

📋 Mode Copier / Coller

Clic droit sur un mot doré → Copier.
Clic droit sur une case vide → Coller.
La vérification est automatique quand toutes les cases sont remplies.

🔢 Déroulement de la partie

Les phrases sont proposées dans l'ordre du fichier, une seule fois chacune. Le badge 📝 Phrase X / N en haut de l'écran indique la phrase en cours et le nombre total de phrases disponibles.
Lorsque la dernière phrase a été jouée, la partie s'arrête et un récapitulatif s'affiche : score, nombre de phrases réussies ou passées, durée, et le détail phrase par phrase.
Ce récapitulatif peut être exporté en PDF : le bouton ouvre la fenêtre d'impression, où il suffit de choisir « Enregistrer au format PDF » comme destination.

✅ Résultats

Bravo vert = bonne réponse ! +1 point.
Message rouge = à retenter, les mots sont remis à disposition.

📁 Utiliser ses propres textes

Par défaut le jeu utilise des textes intégrés. Pour jouer avec vos propres textes, cliquez sur 📁 Choisir un fichier XML manuellement depuis l'accueil et sélectionnez un fichier sur votre ordinateur.
