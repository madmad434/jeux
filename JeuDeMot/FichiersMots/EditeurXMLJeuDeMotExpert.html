🎯 Gestionnaire Jeu de Mot

Gérez votre liste de mots par thème au format XML.

1

📂 Charger un fichier existant

Cliquez sur 📂 Ouvrir XML pour charger un fichier mots.xml. Les mots s'affichent dans la liste à gauche.

2

✏️ Consulter et modifier

Cliquez sur un mot dans la liste. Passez sur l'onglet ✏️ Édition, modifiez, puis 💾 Sauvegarder.

3

➕ Ajouter un mot

Cliquez sur ➕ Nouveau Mot. Choisissez une catégorie dans la liste ou créez-en une nouvelle via — Autre —. Le mot doit comporter au moins 5 caractères.

4

💾 Enregistrer sur le disque

Cliquez sur 💾 Enregistrer pour sauvegarder dans NouveauxMots.xml.

❌ Effet du bouton Annuler

En mode Édition (modification d'un mot existant) : les champs reviennent aux valeurs d'origine, aucune modification n'est appliquée.
En mode Nouveau Mot : la création est abandonnée et la nouvelle entrée (vide) est supprimée. La sélection précédente est restaurée.

⚠️ Important : Sauvegarder enregistre en mémoire uniquement. Utilisez Enregistrer pour écrire définitivement sur le disque.

🆕 Créer un nouveau fichier de zéro

Pas de fichier XML ? Cliquez directement sur ➕ Nouveau Mot sans rien charger, ajoutez vos mots, puis 💾 Enregistrer pour créer NouveauxMots.xml.
