🔤 Gestionnaire Anagrammes — mode expert

Gérez vos groupes d'anagrammes au format XML, sans assistant : tout est accessible en deux clics.

1

📂 Charger une collection

Cliquez sur 📂 Ouvrir XML pour charger un fichier <anagrammes>. Les groupes s'affichent à gauche, classés par longueur.

2

✏️ Consulter et modifier

Cliquez sur un groupe. Passez sur l'onglet ✏️ Édition, modifiez, puis 💾 Sauvegarder.

3

➕ Ajouter un groupe

Cliquez sur ➕ Nouveau groupe. Indiquez la longueur, puis saisissez les mots : le contrôle d'anagramme est fait en direct.

4

💾 Enregistrer sur le disque

Cliquez sur 💾 Enregistrer pour écrire le fichier XML. Les numéros de groupe sont renumérotés proprement.

❌ Effet du bouton Annuler

En modification : les champs reviennent aux valeurs d'origine, rien n'est appliqué.
En création : le nouveau groupe est abandonné et la sélection précédente restaurée.

⚠️ Important : Sauvegarder valide le groupe en mémoire. Utilisez Enregistrer pour écrire définitivement le fichier XML.

🆕 Partir de zéro

Pas de fichier ? Cliquez directement sur ➕ Nouveau groupe sans rien charger, ajoutez vos groupes, puis 💾 Enregistrer.
