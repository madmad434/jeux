📖 Aide & Règles

🎯 Principe du jeu

La grille affiche un mot source en ligne 1. Tous les mots d'un groupe sont des anagrammes les uns des autres (mêmes lettres, arrangements différents). Votre objectif : trouver l'un des autres mots du groupe en un nombre limité d'essais.

Un mot est accepté s'il est un anagramme valide du mot source et qu'il appartient au groupe. Tout autre arrangement de lettres est refusé.

🖊️ Saisie

Tapez votre réponse via le clavier virtuel ou le clavier physique. La ligne 6 est la zone de saisie active. Validez avec Entrée ou le bouton ✓ VALIDER. Les lignes 2 à 5 restent vides — aucun indice de position n'est donné.

⏭ Passer

Le bouton Passer (panneau droit) permet de sauter un groupe à tout moment. La partie continue avec le groupe suivant. Les groupes passés apparaissent avec ⏭ dans le récapitulatif.

📂 Source des mots

Mots intégrés : 100 groupes d'anagrammes de 5 à 14 lettres (10 groupes par longueur), tirés du dictionnaire français.

Fichier XML externe : chargez votre propre collection depuis l'accueil. Format attendu :

<anagrammes>
  <anagramm longueur="5" groupe="1">
    <mot>porte</mot>
    <mot>toper</mot>
    <mot>trope</mot>
  </anagramm>
</anagrammes>

⚙️ Configuration

  • Longueur des mots : restreint les groupes à une longueur précise (5 à 14 lettres) ou laisse toutes les longueurs.
  • Tirage aléatoire : les groupes sont mélangés avant la session — aucun doublon possible. Le mot source est toujours le premier mot du groupe ; la cible est choisie aléatoirement parmi les autres.
  • Tirage séquentiel : si une longueur est définie, les groupes sont parcourus dans l'ordre du fichier et la cible est le 2ème mot du groupe. Si "toutes longueurs", le tirage reste aléatoire.
  • Révéler la 1ère lettre : la première lettre de la cible est pré-affichée dans la zone de saisie.
  • Nombre d'essais : de 3 (difficile) à 10 (facile).
  • Groupes par session : nombre de groupes à jouer consécutivement.

Valeurs par défaut : tirage aléatoire, toutes longueurs, 3 essais, 5 groupes.

🏆 Récapitulatif

En fin de session, un tableau détaille pour chaque groupe : le mot source, le mot tapé au dernier essai, le nombre d'essais utilisés, le temps et le résultat (✅ trouvé / ❌ raté / ⏭ passé). Le bouton 📄 Export PDF génère un document imprimable au format A4.
